# instalar npm
Pasos para instalar Node.js y npm
1. Descarga el instalador: Entra al sitio web oficial de Node.js y descarga la versión LTS (recomendada por ser la más estable).
2. Ejecuta la instalación: Abre el archivo descargado y sigue las instrucciones del asistente (haz clic en Siguiente / Next y acepta los términos hasta finalizar).
3. Verifica la instalación: Abre tu terminal, símbolo del sistema (CMD) o PowerShell y ejecuta los siguientes comandos para comprobar que todo quedó instalado:
	• node -v (muestra la versión de Node.js)
	• npm -v (muestra la versión de npm)
